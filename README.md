## 买机场前先分清

- **月付价和年付折合价**：首页写的“¥8 起”通常是年付总价平摊到每月，要一次付清一年，流量也只有 40–60GB/月。真正按月付款的套餐一般在 ¥18–¥27 之间，详见 [月付和不限时怎么选](https://tuijianjichang.blog/compare/monthly-vs-no-expiry/)。
- **流量够用就好**：查资料、用 AI 每月 50GB 以内够用；天天看视频要 150GB 以上；追 4K 剧或全家共用要 300–600GB。详见 [如何选择套餐](https://tuijianjichang.blog/compare/how-to-choose-plans/)。
- **专线和中转**：IPLC/IEPL 是跨境专线，晚高峰掉速、断流的概率比普通中转小，详见 [IPLC 和 IEPL 的区别](https://tuijianjichang.blog/compare/iplc-vs-iepl/)。
